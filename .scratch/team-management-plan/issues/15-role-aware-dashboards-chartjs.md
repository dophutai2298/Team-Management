# 15: Role-aware dashboards with Chart.js

**What to build:** Build Admin, Parent, and Employee dashboards that show scoped summaries and Chart.js widgets from live MVP queries.

**Blocked by:** 09: Scoped task assignment and multi-assignee progress; 12: Notification center, email service, and reminder jobs; 13: Personal Todo daily checklist; 14: Pomodoro focus sessions and music library.

**Status:** ready-for-agent

- [ ] Admin dashboard shows pending accounts, active employees, overdue tasks, task progress by team, and organization statistics.
- [ ] Parent dashboard shows subtree employees, subtree tasks, overdue tasks, task progress, and team calendar summary.
- [ ] Employee dashboard shows today's tasks, upcoming deadlines, overdue tasks, todo, focus summary, and notifications.
- [ ] Chart.js widgets render scoped dashboard metrics without exposing unauthorized data.
- [ ] Dashboard queries use TanStack Query and show loading, empty, and error states.
- [ ] Dashboard data is live-query based for MVP rather than precomputed.
