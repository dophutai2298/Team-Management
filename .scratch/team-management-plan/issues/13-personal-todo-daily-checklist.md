# 13: Personal Todo daily checklist

**What to build:** Give employees an owner-only daily Todo checklist that is separate from Task and does not affect task assignment or KPI logic.

**Blocked by:** 03: Auth session, registration, and pending access gate; 05: Role, permission catalog, and authorization matrix.

**Status:** ready-for-agent

- [ ] Employees can create, update, complete, and delete their own todo items.
- [ ] Todo items are owner-only and inaccessible to other employees.
- [ ] Todo UI supports daily checklist usage with loading, empty, and error states.
- [ ] Todo data is separate from Task data and cannot be assigned to other users.
- [ ] Todo summary data is available for the Employee dashboard.
- [ ] Todo has no reminders in MVP.
