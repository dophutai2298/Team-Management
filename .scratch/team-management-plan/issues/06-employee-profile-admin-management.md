# 06: Employee profile and admin employee management

**What to build:** Allow employees to maintain personal profile fields while Admins manage official organization fields and employee lifecycle state.

**Blocked by:** 04: Admin account approval workflow; 05: Role, permission catalog, and authorization matrix.

**Status:** ready-for-agent

- [ ] Employees can edit allowed profile fields such as full name, birthday, phone, address, hometown, avatar, timezone, and locale.
- [ ] Employees cannot edit official organization fields such as role, team, manager, position, level, or official employee code.
- [ ] Admin can view, search, and update employees through a data-heavy table experience.
- [ ] Admin changes to role, position, level, manager, team, or status create history records.
- [ ] Disabled or Terminated employees are preserved instead of hard-deleted.
- [ ] Sensitive employee management actions are authorized and audited.
